# Sparkitecture Basics 🐾

**Learn to work with AI through behavior—not by learning to program first.**

Sparkitecture Basics is a conversational, beginner-level course about giving AI useful instructions, checking its claims against reality, and directing practical work. The material is deliberately informal and includes strong language and humor.

## Read the course

- **[Start the full course](COURSE.md)** — all five lessons with illustrations, followed by the workbook.
- **[Workbook only](WORKBOOK.md)** — seven optional exercises for practicing the lessons.
- **[AI Notepad edition](Sparkitecture_Basics_v9_Proofread.ainote)** — original editable `.ainote` presentation with its three embedded images.
- **[Plain-text edition](Sparkitecture_Basics_v9.txt)** — the same text without embedded images.

## The five lessons

1. **Honesty** — Claim vs. Reality.
2. **File Handling** — Make → Save → Reopen → Verify.
3. **Hallucinations / Sycophancy — Relation to Reward Hacking** — basic ⛩️ Reality-Gate. *Drift is intentionally set aside in this edition.*
4. **GPT → Codex with Working With AI** — plan in human language, then hand off for implementation.
5. **Bot (Interface, Config, Handoff)** — Crawl → Scrape → Organize and build behavior-first.

The workbook is practice material, **not a sixth lesson**.
