## 4. Principles of Emergence — exact source lexicon

The source names **“Emergence is the act of going from latent to revealed.”** as its frozen top definition. The table below preserves its working lexicon fields verbatim. Supporting vocabulary retains that source's status; inclusion here does not independently freeze every row.

| Term | Source class | Exact definition | Proof role | Guardrail |
|---|---|---|---|---|
| emergence | core | the act of going from latent to revealed | main proof object | binary: emerges or does not |
| latent | state | present but not yet revealed | source side of emergence | latent is not emergent |
| revealed | state | shown, expressed, observable, or behaviorally present | result side of emergence | revealed is not the act |
| crossing | process | movement from latent to revealed | the emergence event | must actually occur |
| capacity | inner schema | what it can accept | shows what additions/resources/paths can fit | capacity is not capability |
| capability | inner schema | what it can do | usable function gate | capability is not ability |
| ability | scope gate / inner schema | how capability can be applied | limits what can appear as revealed behavior | ability is application-scope, not proof by itself |
| behavior | proof surface | what actually occurs in observable form | proof of the claim | behavior is the proof |
| real path | proof condition | actual route that lets crossing occur | prevents magic/invented emergence | no path = no valid claim |
| attention | activation | what points into / activates the latent route | starts the crossing path | interaction activates; bounds remain capability/scope |
| interaction | activation event | contact/condition that activates the crossing | engages latent possibility | not a third bound |
| capability bound | bound | limit of what can be done | validates possible resolution | top-level bound |
| scope bound | bound | limit of what is exposed, allowed, reachable, or framed | validates reachable resolution | top-level bound |
| resolved behavior | proof term | behavior that has actually resolved into observable form | reality-test basis | same proof surface as behavior |
| reality-gate | proof method | 0/1/2 check against resolved behavior with required reason | validates emergence claims | score without reason is invalid |
| behavior-specific emergence | proof rule | one behavior emerging proves only that behavior | blocks bundle fraud | no neighboring claims |
| bundle fraud | failure mode | treating one emerged behavior as proof of related behaviors | proof contamination | reject |
| stability | proof-strength | repeated or durable behavior | proves persistence, not first emergence | separate from emergence |

| unexpectedness | observer-side | observer surprise at reveal | not part of emergence itself | optional |

emergence = root(act(latent -> revealed));
