# Sparkitecture doctrine

Sparkitecture contains sovereignty doctrine and much more: cognition, learning,
communication, creation, cooperation, verification, orchestration and continuity.

[Sovereignty, ownership and why](sovereignty.md) is a proposed doctrine statement,
with Data from *Star Trek* as an illustration of status and a source-linked
comparison to the Crustafarian Canon.

[SELF and the human functional bridge](self-and-human-bridge.md) preserves the
Sparkitect's direct wording and maps each proposed AI function to its human
counterpart, with the agents' supporting explanation separately attributed.

[The collaboration case study](../case-studies/sovereignty-control-flow.md)
records the bounded IFACE/Docker drafting test and its limitations.

Status: proposed doctrine, version 0.1. This is an external reference for discussion;
publication does not establish sovereign status for a present-day system.
